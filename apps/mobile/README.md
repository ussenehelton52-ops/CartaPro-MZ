# Telas implementadas

## Home Screen
- Exibição do progresso do estudante
- Grid de ações rápidas para estudar, fazer exames, ver sinais, etc.

## Exam Screen
- Interface de questão com múltiplas escolhas
- Sistema de feedback imediato (resposta correta/errada)
- Explicações após cada questão
- Barra de progresso
- Resultado final com percentual de acerto

## Signals Screen
- Visualização de sinais de trânsito organizados por categoria
- Categorias: Proibição, Obrigação, Perigo, Informação

## Progress Screen
- Visualização do progresso geral em percentual
- Estatísticas de acertos/erros
- Sistema de conquistas/badges
